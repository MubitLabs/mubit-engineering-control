# M3 — Droplet provisioning and deploy pipeline

## What it does

Puts the control plane on `droplet-max` (139.59.181.123) at
**https://mec.139-59-181-123.sslip.io**, next to the existing OpenClaw and builderprofile services
without touching them.

| Piece | Where |
| --- | --- |
| PostgreSQL 16 (apt), database + role `mec`, listening on localhost only | host |
| 4 GB `/swapfile`, `vm.swappiness=10` | host |
| `mec` system user; state in `/var/lib/mec` (artifacts, backups) | host |
| Config + secrets: `/etc/mec/control.env` (root:mec 0640), written once, never in git | host |
| `mec-control.service` (User=mec, hardened, 700 MB cap) | `deploy/systemd/` |
| `mec-runner.service` (User=max, so it uses max's native Claude login) — enabled in M4 | `deploy/systemd/` |
| Caddy site → `127.0.0.1:4100`, SSE unbuffered and uncompressed | `deploy/caddy/mec.caddy` |
| Daily `pg_dump` at 03:17, 14 days kept | `/etc/cron.d/mec-backup` |

`deploy/deploy.sh` builds locally (the droplet has little RAM), rsyncs a release to
`/opt/mec/releases/<utc-time>-<sha>`, installs production dependencies, runs migrations as `mec`,
switches `/opt/mec/current`, restarts, and health-checks. The three newest releases are kept, so a
rollback is `ln -sfn` + restart.

Two fixes came out of this milestone:

- Open SSE streams are now ended on shutdown (`preClose`), so `systemctl restart` is not held
  up by a connected browser.
- GitHub mode starts with sign-in disabled when the OAuth app is not configured yet, instead of
  crash-looping.

## How to read it

Start with `deploy/provision.sh` (idempotent, every step guarded) and then `deploy/deploy.sh`.

## How to demo

```bash
deploy/deploy.sh provision   # first time, or after changing deploy/
deploy/deploy.sh             # every later release
curl https://mec.139-59-181-123.sslip.io/healthz
ssh openclaw systemctl status mec-control
```

Sign-in needs a GitHub OAuth App in MubitLabs with callback
`https://mec.139-59-181-123.sslip.io/auth/github/callback`; its client ID and secret go into
`/etc/mec/control.env` as `GITHUB_CLIENT_ID` / `GITHUB_CLIENT_SECRET`, followed by
`systemctl restart mec-control`. Non-members of MubitLabs are refused.
