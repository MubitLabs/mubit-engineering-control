# Architecture decisions

Add a record only for a consequential choice with a useful rationale.
Name records NNN-short-title.md; use the extracted kit's DECISION.md template.
Include status, context, choice, alternatives, consequences, and source/PR
references. Mark superseded decisions and link their replacements. Current
architecture documentation should reflect the decision after implementation.

## This repository

The canonical owner-decision record is `docs/DECISIONS.md` (seven binding product decisions + #8, the build-era operator authority). Owner decisions are appended there by the owner or with the owner's explicit answer; use ADR files in this directory only for architecture choices that merit their own record with alternatives and consequences.
